# 国立国語研究所 教育基本語彙データベース

`02-candidates/source-pool.tsv`と`05-output/dictionary.json`の生成には、国立国語研究所の次のデータを利用しています。

- 教育基本語彙データベース（2009A）
  - https://mmsrv.ninjal.ac.jp/brfvep/kyoikukihongoi_2009A.csv
- 日本語教育基本語彙データベース
  - https://mmsrv.ninjal.ac.jp/brfvep/rokusyutaisyo.csv

提供者: 大学共同利用機関法人人間文化研究機構 国立国語研究所
